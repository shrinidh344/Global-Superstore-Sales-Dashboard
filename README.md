# Global-Superstore-Sales-Dashboard
Interactive Power BI dashboard for analyzing Global Superstore sales, regional performance, product profitability, top-selling products, and returns.

## Dashboard Preview

![Global Superstore Sales Dashboard](assets/sales-dashboard-preview.png)

## Key Performance Indicators

- **Total Sales** — overall sales value.
- **Total Orders** — distinct order count.
- **Returns** — returned orders.
- **Return Percentage** — proportion of orders returned.

## Dashboard Highlights

- **Sales Trend:** View sales performance over time.
- **Sales by Region:** Compare sales across geographic regions.
- **Sales by Product Category:** Review sales contribution from each product category.
- **Top 10 Products by Sales:** Identify the highest-selling products.
- **Profit by Sub-Category:** Compare profitability across product sub-categories, including negative-profit results.
- **Return Rate by Region:** Compare return activity across regions.
- **Regional Sales & Profit Matrix:** Explore regional performance across product categories using sales and profit values.

## Interactive Filters

Use the report slicers to filter the dashboard by:

- Year
- Market
- Ship Mode

The visuals respond to report selections, helping compare sales and profitability across different slices of the business.

## Tools & Technologies

- **Microsoft Power BI Desktop** — report creation and interactive visualisation
- **Power Query** — data preparation
- **DAX** — measures and calculations
- **Global Superstore dataset** — sales, orders, products, returns, and regional information
